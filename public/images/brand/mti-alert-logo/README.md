# MTI Alert logo concept

Original application identity designed on 2026-09-12. Diagonal geometric ribbons echo the angular industrial forms of the user-requested PT Merdeka Tsingshan Indonesia reference. The copper signal dot adds an alert cue. This is an MTI Alert application concept, not a replacement for the corporate logo.

- Copper: #B24F26
- Graphite: #303D49
- logo.svg: horizontal wordmark, canonical editable source.
- logo-icon.svg: square mark for small placements.
- PNG renders: transparent backgrounds, 1600px lockup and 1024px icon.
- Generic Helvetica Neue / Arial / sans-serif typography; no external fonts or image dependencies.

Logo reference inspected: https://karirindustri.com/wp-content/uploads/2025/08/Merdeka-Tsingshan-New-Thumbnail.png
Corporate artwork sources are recorded separately in ../README.md. The login corporate row uses MTI, MCG and MBM.
